Applications

Une application = un nom + une ou plusieurs URL de base. Les pages sont identifiées par leur chemin relatif à l'URL de base : https://srv/client1/factures et https://srv/client2/factures tombent dans la même colonne /factures. Après un ajout, rechargez les onglets déjà ouverts sur ces applications.

Mesure

ms

Plus d'activité réseau (fetch/XHR) ni de modification de la page pendant ce délai. Ce délai n'est pas ajouté au temps mesuré : la fin retenue est l'instant de la dernière activité.

s

Au-delà, la mesure est enregistrée comme « timeout » (case grise).

Données

Astuce : mesurez en WiFi sur un poste et en Ethernet sur un autre, puis importez la sauvegarde de l'un dans l'autre pour obtenir un rapport complet (applications reconnues par leur nom, doublons ignorés).

Import en masse

Une application par ligne : Nom;URL. Copiez-collez directement deux colonnes depuis Excel (nom, URL). Plusieurs URL pour une même appli : séparez-les par |. Une ligne avec seulement une URL crée une appli nommée d'après l'URL. Une appli existante (même nom) reçoit les nouvelles URL.
