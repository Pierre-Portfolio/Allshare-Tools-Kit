Clients

Les clients proposés dans le formulaire de mesure. Les clients mesurés s'ajoutent tout seuls. L'URL est facultative : si elle est renseignée, le client est pré-rempli quand l'onglet est sur son application. Renommer un client renomme aussi ses mesures (et fusionne si le nom existe déjà). Supprimer un client supprime aussi toutes ses mesures.

Données

Astuce : mesurez en WiFi sur un poste et en Ethernet sur un autre, puis importez la sauvegarde de l'un dans l'autre pour obtenir un rapport complet (clients reconnus par leur nom, doublons ignorés).

Import en masse

Un client par ligne : Nom ou Nom;URL. Copiez-collez directement une ou deux colonnes depuis Excel. Plusieurs URL pour un même client : séparez-les par |. Un client existant (même nom) reçoit les nouvelles URL.
